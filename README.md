# سایت تست شبکه ننوتو

سایت کامل و تست برای کانال **شبکه ننوتو** (@nanoto_tv)

## صفحات موجود

| فایل | توضیح |
|------|--------|
| `index.html` | صفحه اصلی — هیرو، آمار، آخرین پست‌ها، کانال‌های مرتبط |
| `archive.html` | آرشیو میم‌ها با فیلتر و جستجو |
| `about.html` | درباره کانال و هویت برند |
| `submit.html` | فرم ارسال سوژه و گزارش |
| `ads.html` | صفحه تبلیغات + فرم هماهنگی |
| `links.html` | لینک‌تری کامل همه پلتفرم‌ها |

## ویژگی‌ها

- طراحی تاریک و مدرن مطابق هویت طنز کانال
- کاملاً راست‌چین (RTL) و فونت وزیرمتن
- ریسپانسیو (موبایل و دسکتاپ)
- فیلتر و جستجو در آرشیو
- فرم‌های تعاملی (ارسال سوژه و تبلیغات)
- لینک‌های واقعی به همه شبکه‌های اجتماعی کانال
- آمار واقعی کانال (حدود ۵۶ هزار دنبال‌کننده)

## نحوه اجرا

فقط فایل‌ها را باز کنید یا روی هر هاستی آپلود کنید:

```bash
# اگر می‌خواهید لوکال سرور داشته باشید:
npx serve .
# یا
python -m http.server 8000
```

سپس مرورگر را روی `http://localhost:8000` باز کنید.

## نکات

- این یک نسخه **تست و دمو** است.
- فرم‌ها فقط پیام موفقیت نشان می‌دهند (بک‌اند ندارند).
- برای نسخه واقعی می‌توانید به Cloudflare Pages یا هر هاست استاتیک آپلود کنید.
- محتوای پست‌ها بر اساس پست‌های واقعی کانال شبیه‌سازی شده‌اند.
